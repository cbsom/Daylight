# Image sources

`world.jpg`: the original map currently used in both flat and globe views. NASA Blue Marble Next Generation, October 2004, topography.
https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography/

`earth-and-sky.png` and `earth-and-sky.ico`: orthographic globe derived from `world.jpg`,
with half-day, half-night shading. Generated by `../tools/make-icon.cpp`.
The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel versions.

`moon-full.jpg`: FullMoon2010.jpg, Gregory H. Revera, CC BY-SA 3.0.
https://commons.wikimedia.org/wiki/File:FullMoon2010.jpg
https://creativecommons.org/licenses/by-sa/3.0/

The original Moon photograph is preserved. Runtime adaptations crop its black
margins, resize it, and darken the unilluminated area according to the calculated
lunar phase. The adapted lunar imagery is also licensed under CC BY-SA 3.0.

`world_changed.jpg` is the modified map retained for comparison; it is not currently embedded in the executable. The existing runtime brightness adjustment in `dayImage()` is applied to the original map.
